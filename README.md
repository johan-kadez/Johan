# LUXURYCPM
Store hitam-emas responsive untuk Car Parking Multiplayer.

## File
- index.html — store
- admin.html — panel admin
- vercel.json — rewrite /admin

## Catatan
Versi ini mempertahankan identitas LUXURYCPM hitam-emas. Desktop membuat filter/search terpusat di tengah container produk, sedangkan HP dibuat full-width dan touch-friendly.
